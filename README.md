# Homebrew Tap

Custom tap for personal macOS utilities.

## Contents
- `miso` – Method Input Switch Overlay.
- `app-detective` – System analyzer utility.
- `staged-launcher` – Stage Manager helper.
- `remote-launcher` – High Performance Screen Sharing launcher for remote Macs.
- `amux` – Tiny CLI that keeps local AI/code agents organized inside tmux.
- `github-desktop-tip` – GitHub Desktop tip build (cask).
- `font-hanori` – Hanori Sans/Serif fonts for English, Chinese, and Japanese with optional furigana (cask).
- `hanori-preview` – Hanori font preview app with a Safari extension for Japanese readings (cask).

## Usage

```bash
brew tap hewigovens/tap
brew install --cask miso
```

Or
```bash
brew install --cask hewigovens/tap/miso
```
